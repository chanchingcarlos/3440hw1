Q1(a) Exhaustive enumeration (25 marks)

Problem recap: max z = 6.5x1 + 5x2, s.t. 2x1+2x2 ≤ 7 (1), 2x1+x2 ≤ 5 (2), x1+x2 ≥ 1 (3), x1,x2 ≥ 0 integer.
Answer: 16 candidate integer points (x1,x2 in {0,1,2,3}), 8 feasible; optimal (x1*,x2*) = (2,1), z* = 18。
Follow the example (cf. Example 2.8, ch02-3.pdf pp.20–22):
1. The example fixes a box first; here 2x1 ≤ 7, 2x2 ≤ 7 give x1,x2 ∈ {0,1,2,3}.
2. The example checks each point and computes z; here check (1)(2)(3) + z per point (table Feasible? column marks violated constraints in brackets after N).
3. The example compares z for the max; here compare z over 8 feasible points, (2,1) with 18 is max.
4. For submission list all 16 points in the example table format (x1, x2, Feasible?, z).

Q1(b) PIP branch-and-bound (25 marks)

Problem recap: Solve Q1 by PIP branch-and-bound and draw the B&B tree; each subproblem LP relaxation solved graphically.
Answer: LP0 (1.5,2) z=19.75: branch x1; LP1 (1,2.5) z=19: branch x2; LP2 (2,1) z=18 integer, z*=18; LP3 (1,2) z=16.5 fathomed; LP4 (0.5,3) z=18.25: branch x1; LP5 (0,3.5) z=17.5 <= 18 fathomed; LP6 infeasible, fathomed.optimum (2,1), z* = 18。
Follow the example (cf. 2-D PIP example, ch02-3.pdf pp.36–45; overview pp.31–35):
1. Initialize z* = −∞ and solve the original LP relaxation for a bound (example LP0 23.75; here LP0 (1.5,2) 19.75).
2. Try all three fathoming tests one by one (as in example p.2:38: write down Test 1/2/3 passed/failed).
3. Always branch the first fractional variable (natural order), adding xj ≤ floor / xj ≥ floor+1 (example x1 = 3.75 → x1 ≤ 3 / x1 ≥ 4; here x1 = 1.5 → x1 ≤ 1 / x1 ≥ 2).
4. An integer solution is fathomed (test 3) at once and updates the incumbent; finish with a test-1 sweep over remaining nodes — none left means optimal.
5. Draw the tree as in example p.2:45: each node shows the LP relaxation solution + z bound, plus the current incumbent.

Q2(a) BIP exhaustive enumeration (25 marks)

Problem recap: max z = 3x1+3x2+5x3−2x4−x5, s.t. x1+2x2−3x4−x5 ≤ 0 (1), −15x1+30x2−35x3+45x4+45x5 ≥ 50 (2), xj ∈ {0,1}.
Answer: 9 of 32 binary points feasible; optimal (1,1,1,1,1), z* = 8 (unique)。
Follow the example (cf. BIP definition p.3, 2ⁿ complexity pp.23–24, Example 2.8 table pp.20–22):
1. n = 5 binary variables → 2⁵ = 32 points (Example 2.9 explains why enumeration explodes, but n = 5 is doable).
2. Compute three numbers per point: (1) LHS (need ≤ 0), (2) LHS (need ≥ 50, watch the direction), z.
3. Warning: highest z is not optimal — (1,1,1,0,0) has z = 11 but (2) LHS = −20, infeasible.
4. For submission list all 32 points (x, z, Feasible?); 9 feasible, optimum (1,1,1,1,1) z = 8 unique.

Q2(b) BIP branch-and-bound (25 marks)

Problem recap: Solve Q2 by BIP branch-and-bound; each subproblem LP relaxation solved by an LP solver (computer printouts shown).
Answer: LP0 (1,1,1,0.7222,0.8333) z=8.7222: branch x4; x4=0 branch LP1 z=1.9286 (later fathomed by z*=8); x4=1 branch LP2 z=8.4444: branch x5; LP3 (x5=0) z=5.4286 fathomed; LP4 (x5=1) = (1,1,1,1,1) integer, z=8.optimum (1,1,1,1,1), z* = 8。
Follow the example (cf. BIP full example, ch02-3.pdf pp.74–93):
1. First rewrite: xj binary equals 0 ≤ xj ≤ 1 plus integrality (example pp.75–76); dropping integrality gives LP0.
2. Branch by fixing x = 0 / x = 1 directly, not floor splits (example pp.78–79; here branch x4 then x5).
3. Keep the solver printout per node: x + z bound (here LP0 8.7222, LP2 8.4444, LP1 1.9286, LP3 5.4286, LP4 integer 8).
4. After the integer solution (test 3) updates z* = 8, fathom BIP1/BIP3 with test 1 (as in example p.92).
5. Draw the tree as in example p.93: BIP0 → {BIP1, BIP2}; BIP2 → {BIP3, BIP4}.
